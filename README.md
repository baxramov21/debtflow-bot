# DentFlow Telegram Bot Service

This is a standalone patient self-service Telegram bot service for DentFlow.
It shares the DentFlow Supabase database but operates independently.

## Setup

1. Copy `.env.example` to `.env.local`
2. Fill in the environment variables (these should match your DentFlow Supabase instance)
3. Run `npm install`
4. Run `npm run dev` to start the Next.js server locally
